# ТАРАСВІТ — лендинг HDPE-тари

Сайт виробника HDPE-тари ТАРАСВІТ (м. Чернігів): тара, укупорка, комплекти, контакти та форма заявки.
Статична сторінка без залежностей: `index.html` + папка `img/`.

## Структура

| Шлях | Що це |
| --- | --- |
| `index.html` | Готова сторінка, зібрана з `src/` |
| `img/` | Зображення WebP: тара, укупорка, сцени |
| `src/data.py` | Дані товарів: тара, дозатори, тригери, кришки, комплекти. Єдине джерело цифр |
| `src/page.html` | Розмітка й тексти блоків |
| `src/style.css` | Стилі: токени кольорів, світла й темна тема, адаптив |
| `src/app.js` | Вкладки каталогу, меню, форма, кнопки копіювання |
| `src/build.py` | Збирає `index.html` з файлів `src/` |
| `apps-script/Code.gs` | Приймач заявок: записує кожну заявку з форми в Google Таблицю |

## Як змінити

1. Відредагуйте файли в `src/`.
2. Запустіть `python3 src/build.py` (Python 3.8+, без сторонніх пакетів).
3. Закомітьте оновлений `index.html`.

## Як опублікувати

- **GitHub Pages:** Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`. Адреса буде `https://dornaxenia.github.io/tarasvit/`.
- **Будь-який статичний хостинг:** завантажте `index.html` і папку `img/`.

## Заявки в Google Таблицю

Форма надсилає кожну заявку окремим рядком у Google Таблицю. Приймач: Google Apps Script `apps-script/Code.gs`, прив’язаний до самої таблиці. Сторонніх сервісів немає.

Колонки аркуша «Заявки»: Дата і час · Статус · Ім’я · Телефон · E-mail · Компанія · Напрямки · Коментар · Кнопка / товар · Сторінка · Звідки прийшов · utm_source · utm_medium · utm_campaign · utm_term · utm_content · ID заявки.

### Підключення (один раз)

1. Відкрийте таблицю → **Розширення → Apps Script**.
2. Видаліть вміст `Code.gs`, вставте код з `apps-script/Code.gs`, збережіть (Ctrl+S).
3. У списку функцій угорі оберіть `setup` → **Виконати**. Надайте доступ: оберіть обліковий запис → «Додатково» → «Перейти до … (небезпечно)» → «Дозволити». Google показує це попередження для будь-якого власного скрипта без верифікації. Після цього в таблиці з’явиться аркуш «Заявки» із заголовками.
4. **Розгорнути → Нове розгортання** → тип «Веб-застосунок». Виконувати від імені: **Я**. Хто має доступ: **Усі** (Anyone). Розгорнути.
5. Скопіюйте URL веб-застосунку (закінчується на `/exec`). Перевірка: відкрийте його в браузері, має з’явитися `{"ok":true,"service":"tarasvit-leads"}`.
6. Вставте URL у `src/data.py` → `CONTACT["lead_endpoint"]`, запустіть `python3 src/build.py`, закомітьте `index.html`. Кнопка форми зміниться на «Надіслати заявку».
7. Надішліть тестову заявку з опублікованого сайту й перевірте рядок у таблиці.

Після змін у `Code.gs`: **Розгорнути → Керування розгортаннями → ✎ → Версія: Нова версія → Розгорнути**. URL не зміниться.

### Як працює

- Сайт надсилає POST із JSON як `text/plain`: це простий запит без CORS preflight, Apps Script приймає його й відповідає JSON.
- Відповідь `ok` → екран «Дякуємо, заявку прийнято». Збій, тайм-аут 15 с або відмова → екран із текстом заявки, кнопками «Спробувати ще раз», «Скопіювати заявку», «Написати на e-mail». Повтор надсилає той самий ID заявки, тому дубля в таблиці не буде.
- Захист: приховане поле-пастка для ботів, мінімальний час заповнення 1,5 с, ліміт 30 заявок за 10 хв, обмеження довжини полів. Значення, що починаються з `= + - @`, записуються як текст (захист від формул).
- Поки `lead_endpoint` порожній, форма працює як раніше: «Сформувати заявку» → копіювання або лист на sales.tarasvit@gmail.com.

## Що ще не готово

- **Приймач заявок** треба розгорнути за інструкцією вище й вписати його URL у `src/data.py`.
- **Зображення:** фото тари та кришки створені в Canva за фото продукції; сцени в блоках «Для кого» та на першому екрані — AI-ілюстрації. Бажано замінити на студійні фото й фото виробництва.
- **Дані, які чекають підтвердження:** вага каністри ФОРТЕ ПЛЮС, стандарти різьби горловин, артикул зеленої кришки 38 мм.
