# ТАРАСВІТ — лендинг HDPE-тари

Сайт виробника HDPE-тари ТАРАСВІТ (м. Чернігів): тара, укупорка, комплекти, контакти та форма заявки.
Статична сторінка без залежностей: `index.html` + папка `img/`.

## Структура

| Шлях | Що це |
| --- | --- |
| `index.html` | Готова сторінка, зібрана з `src/` |
| `img/` | Зображення WebP: тара, укупорка, сцени |
| `src/data.py` | Дані товарів: тара, дозатори, тригери, кришки, комплекти. Єдине джерело цифр |
| `src/page.html` | Розмітка й тексти блоків |
| `src/style.css` | Стилі: токени кольорів, світла й темна тема, адаптив |
| `src/app.js` | Вкладки каталогу, меню, форма, кнопки копіювання |
| `src/build.py` | Збирає `index.html` з файлів `src/` |

## Як змінити

1. Відредагуйте файли в `src/`.
2. Запустіть `python3 src/build.py` (Python 3.8+, без сторонніх пакетів).
3. Закомітьте оновлений `index.html`.

## Як опублікувати

- **GitHub Pages:** Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`. Адреса буде `https://dornaxenia.github.io/tarasvit/`.
- **Будь-який статичний хостинг:** завантажте `index.html` і папку `img/`.

## Що ще не готово

- **Форма заявки** поки не має обробника. Кнопка «Сформувати заявку» збирає текст заявки: відвідувач копіює його або надсилає листом на sales.tarasvit@gmail.com. Для прийому заявок потрібен бекенд або сервіс форм; після підключення поверніть кнопку «Надіслати заявку» та екран «Дякуємо, заявку прийнято».
- **Зображення:** фото тари та кришки створені в Canva за фото продукції; сцени в блоках «Для кого» та на першому екрані — AI-ілюстрації. Бажано замінити на студійні фото й фото виробництва.
- **Дані, які чекають підтвердження:** вага каністри ФОРТЕ ПЛЮС, стандарти різьби горловин, артикул зеленої кришки 38 мм.
